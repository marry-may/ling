# Ling

Мобильная PWA-читалка в духе LingQ: импорт EPUB, PDF, TXT и MD, перевод слов по нажатию, словарь и интервальное повторение.

## Как это работает

- **Языки.** При первом запуске выбирается изучаемый язык. Сверху в библиотеке переключатель активных языков и кнопка «Добавить язык». Открывается язык, в котором занималась последний раз, а если в нём пусто — язык с наибольшим числом книг. Язык EPUB берётся из метаданных; для TXT, MD и PDF он определяется по тексту.
- **Прогресс.** Для каждого языка видны серия дней подряд, общее число дней занятий (с отметками за неделю), количество знакомых слов и слов на повторении. Статистика хранится на устройстве, а для аккаунта — в профиле пользователя Supabase (`user_metadata.ling_profile`).
- **Перевод.** Три источника опрашиваются параллельно: Google Translate (основной перевод и словарные варианты по частям речи), русский Викисловарь (словарные значения) и MyMemory. Результаты объединяются без повторов. Google используется через неофициальный бесплатный доступ, без гарантий доступности.
- **PDF без текстового слоя** (сканы, «Microsoft Print to PDF») распознаются через OCR (tesseract.js) прямо в браузере. Нужен интернет: модели распознавания загружаются из CDN.
- **Большие книги.** Книга длиннее ~12 000 слов при загрузке делится на части по ~8 000 слов. EPUB делится по границам глав, часть называется по первой главе. Части лежат в одной папке на полке: у папки общий прогресс, у каждой части свой, в конце части есть кнопка «Следующая часть». В облаке части хранятся в одной папке хранилища (`<user>/<collection>/part-NNN.txt`), исходный файл один на всю книгу.
- **Статусы слов в тексте.** Синие — новые, жёлтые — сохранённые (уровни 1–4, чем выше уровень, тем бледнее подсветка), без подсветки — известные.
- **Чтение по страницам** (~220 слов). Кнопка «Знаю новые и дальше» отмечает все синие слова страницы как известные и перелистывает. Стрелки ← → тоже листают. Позиция чтения сохраняется.
- **Тренировка.** Подход из 10 слов, в конце итог с ошибками и кнопкой «Повторить ошибки». Упражнения: карточки, выбор перевода из 4, перевод → слово, сборка слова из букв, написание слова, или микс. Слова: рекомендуемые (дольше всего не повторялись), случайные или выбранные вручную. Ошибка возвращает слово на уровень 1, верный ответ по наступившему сроку повышает уровень (повторение через 1, 3, 7 дней).

```sh
npm ci

```

## Публикация на ling.uno

```sh
npm ci
npm run build
```

1. Проверь `.env.local`: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` и `VITE_SITE_URL=https://ling.uno/` попадают в сборку. `SUPABASE_DB_URL` в сборку не попадает (нет приставки `VITE_`).
2. Загрузи **содержимое** папки `dist/` (или распакуй `dist.zip`) в корень сайта, вместе со скрытым файлом `.htaccess`. Старые файлы из `assets/` можно удалить: у новых другие имена.
3. Сайт должен открываться по HTTPS: без него не работают service worker и установка приложения.
4. `.htaccess` настраивает Apache: `.mjs` отдаётся как JavaScript (иначе не откроются PDF), `index.html` и `sw.js` не кэшируются (иначе посетители застрянут на старой версии). На nginx и других серверах эти правила нужно повторить в их настройках.

После загрузки новой версии открытое приложение обновится само при следующем запуске.

## Аккаунты и облачная библиотека

1. Создай проект Supabase.
2. В SQL Editor по очереди выполни миграции из `supabase/migrations/`: `20261004000000_cloud_library.sql` создаёт таблицы, RLS-политики и приватный bucket `book-files`; `20261004120000_languages_and_review.sql` добавляет языки, данные для повторения и таблицу известных слов; `20261005090000_book_parts.sql` добавляет поля для частей больших книг. Если вторая миграция не применена, приложение откроет локальную копию и сообщит, что нет связи с аккаунтом.
3. Скопируй `.env.example` в `.env.local` и укажи Project URL и publishable/anon key из настроек Supabase. Service-role key в клиентское приложение добавлять нельзя.
4. В Supabase → Authentication → URL Configuration укажи Site URL `https://ling.uno` и добавь в Redirect URLs `https://ling.uno/**` и `http://localhost:5173/**`. Ссылки в письмах подтверждения ведут на `VITE_SITE_URL`.
   Встроенная почта Supabase отправляет письма только участникам проекта и не больше нескольких в час. Для настоящих пользователей подключи свой SMTP (Authentication → Emails → SMTP Settings) или отключи подтверждение почты.
5. Выполни `npm run dev` или `npm run build` повторно после изменения env.

### Миграции из терминала

Новые миграции можно применять без SQL Editor: добавь в `.env.local` строку `SUPABASE_DB_URL` (пример в `.env.example`, без приставки `VITE_`, иначе пароль базы попадёт в приложение) и выполни:

```sh
npm run db:migrate
```

Скрипт применяет по порядку миграции из `supabase/migrations/`, которых ещё нет в `supabase_migrations.schema_migrations`, каждую в отдельной транзакции. Миграции, выполненные вручную, отмечаются командой `npm run db:migrate -- --mark-applied <версия>`.

Вход выполняется по email и паролю. При первом входе гостевые книги и слова загружаются в аккаунт. Новые оригиналы книг и текст для чтения хранятся в приватном bucket; скачивать их могут только владелец.

## iOS и TestFlight

Для разработки требуется macOS с Xcode. Перед распространением задай уникальный Apple Bundle ID в `capacitor.config.ts`, затем настрой Supabase env и запусти:

```sh
npm run ios:sync
npm run ios:open
```

В Xcode выбери Apple Developer Team, проверь signing и запусти App на симуляторе или подключённом iPhone. Для TestFlight создай Archive и отправь его в App Store Connect. Для загрузки на iPhone достаточно бесплатной Apple ID; распространение через TestFlight требует участия в Apple Developer Program.

Пользовательские данные привязаны к аккаунту Supabase и синхронизируются между устройствами. Для офлайн-чтения книга должна быть ранее загружена на это устройство; перевод слова требует интернет-соединения.
